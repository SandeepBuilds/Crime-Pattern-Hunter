07 / PROJECT FILE

Behind the investigation.

Project Objective

Crime Pattern Hunter analyses historical Indian crime records to discover recurring patterns, compare crime categories, explore geographical distributions and understand time-based trends using machine learning.

Why this project?

Large datasets contain information that can be difficult to understand by examining individual records. Data analytics helps transform these records into meaningful visual insights.
