# 🔍 Crime Pattern Hunter
### Uncovering Hidden Patterns in Crime Data Using Machine Learning

## 📌 About the Project
Crime Pattern Hunter is a machine learning-based web application developed to analyze crime data and uncover hidden patterns. It uses data analysis, machine learning algorithms, and interactive visualizations to identify crime trends, clusters, and unusual occurrences.

## 🎯 Objectives
- Analyze historical crime data.
- Identify patterns and trends in criminal activities.
- Group similar crime records using machine learning.
- Detect unusual crime occurrences.
- Present insights through interactive visualizations.

## 🚀 Key Features
- Crime data analysis and visualization.
- Interactive dashboard.
- Crime pattern identification.
- K-Means clustering.
- Anomaly detection using Isolation Forest.
- Data-driven crime insights.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Backend:** Flask
- **Frontend:** HTML, CSS, JavaScript

## 🧠 Machine Learning Algorithms
1. **K-Means Clustering:** Groups similar crime records based on their characteristics.
2. **Isolation Forest:** Identifies unusual data points that may represent anomalous crime patterns.
